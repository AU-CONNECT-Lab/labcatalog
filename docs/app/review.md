# Review

**Review**, the last step of the Set up page, looks over the data as the catalog reads it, before the analyses. The files of one study from one reporter and modality that give the same instruments are shown together, one line per wave marked with the wave's colour: its rows and IDs; how many of the answers its instruments ask for it holds; how many cells hold a missing code and how many a value the item does not allow; and how many errors and warnings Problems lists for it, with **Open** to the file's page on the Datasets page. Below them, a table has one row per score, and per number that is in no score, such as a pipeline's measure, and in each cell one line per wave: n, how many rows have no score (and their share), mean and SD, and α; the last column draws each wave's histogram of the score as a line in its colour, on one scale, to spot a score piled up at one end or a wave that differs; **Each wave apart** draws them as bars, one wave under another, on the same scale. **Next** goes on to Problems.
