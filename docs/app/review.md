# Reviewing the Data

**Review**, beside **List** at the top of the [Datasets](datasets.md) page, looks over the data as the catalog reads it, before the analyses. **Next: Review the data** at the end of the Check IDs step of the Set up page opens it. It shows the datasets the search and filters leave, one panel per series: the files of one study from one reporter and modality that give the same instruments are shown together, one line per wave marked with the wave's colour: its rows and IDs; how many of the answers its instruments ask for it holds; how many cells hold a missing code and how many a value the item does not allow; and how many errors and warnings Problems lists for it, with **Open** to the file's page on the Datasets page. Below them, a table has one row per score, and per number that is in no score, such as a pipeline's measure, and in each cell one line per wave: n, how many rows have no score (and their share), mean and SD, and α; a dash where a wave lacks the score. The last column draws each wave's histogram of the score on its own line, in the wave's colour and on one scale, to spot a score piled up at one end or a wave that differs.
